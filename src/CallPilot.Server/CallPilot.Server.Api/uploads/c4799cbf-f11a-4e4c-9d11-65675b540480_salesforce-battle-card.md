# Competitive Battle Card: Salesforce vs CallPilot AI

## Salesforce Sales Cloud

### Strengths
- Market leader in CRM
- Extensive ecosystem
- Strong brand recognition

### Weaknesses
- Expensive per-user pricing ($150-300/user/month)
- Complex implementation (3-6 months)
- Limited real-time AI capabilities
- Meeting intelligence requires separate add-ons

### Common Customer Complaints
- "Pricing became too expensive"
- "Too complex for our needs"
- "Sales team finds it difficult to use"
- "AI features feel bolted on"

## Why Customers Switch from Salesforce

1. **Cost reduction**: CallPilot AI starts at $29/user/month vs Salesforce's $150+
2. **Real-time AI**: CallPilot AI provides live meeting intelligence, not post-meeting summaries
3. **Faster setup**: Deploy in hours, not months
4. **Open source**: Full access to source code, no vendor lock-in

## Migration Path

### Week 1: Setup & Import
- Install CallPilot AI (Docker Compose or Cloud)
- Import knowledge documents
- Configure AI providers
- Set up Desktop Agent

### Week 2: Pilot
- Run 5-10 test meetings
- Gather feedback
- Adjust AI settings

### Week 3-4: Team Rollout
- Train sales team
- Enable for all meetings
- Review analytics and recommendations
